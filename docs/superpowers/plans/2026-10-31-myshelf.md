# MyShelf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เว็บแอปบันทึกชั้นวางหนังสือ (Google login, ค้นหาผ่าน Google Books, สแกน ISBN, สถานะ อยากอ่าน/กำลังอ่าน/อ่านแล้ว)

**Architecture:** Next.js App Router (TypeScript) เป็น fullstack เดียว — API routes เรียก Google Books ฝั่ง server (ซ่อน API key), Prisma ต่อ Supabase Postgres, Auth.js v5 + Google provider พร้อม email allowlist. หน้าบ้านเป็น client components เรียก API ผ่าน fetch.

**Tech Stack:** Next.js 15 (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, next-themes, Auth.js v5 (`next-auth@beta` + `@auth/prisma-adapter`), Prisma, Supabase (Postgres pooler), Vitest, IBM Plex Sans Thai.

**Spec:** `docs/superpowers/specs/2026-10-31-myshelf-design.md`

## Global Constraints

- UI สองภาษา TH/EN (i18n) — default ไทย, สลับได้จาก NavBar, เก็บใน cookie `locale`; ฟอนต์หลัก IBM Plex Sans Thai ทั้งเว็บ
- สี: พื้นครีม `#F7F5F0`, ตัวอักษรเทาเข้ม `#2B2B28`, accent sage `#5F7A61` + dark mode ผ่าน next-themes
- สถานะ enum (Prisma): `WANT_TO_READ | READING | READ` — label ไทย: อยากอ่าน / กำลังอ่าน / อ่านแล้ว
- ทุก API route ของ books/shelf ตรวจ session ก่อน (401 ถ้าไม่ล็อกอิน); user เห็น/แก้เฉพาะ ShelfItem ของตัวเอง
- คีย์ทั้งหมดอยู่ใน env เท่านั้น (`GOOGLE_BOOKS_API_KEY`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `DATABASE_URL`, `DIRECT_URL`, `AUTH_SECRET`, `ALLOWED_EMAILS`, `AUTH_OWNER_EMAIL`, `NEXT_PUBLIC_APP_URL`)
- ไม่เพิ่ม Supabase Storage; ปก manual book เป็น placeholder จากตัวอักษรแรก + สีจาก hash
- Windows/PowerShell environment — ใช้ `npm` ทั้งหมด
- Dependency ใหม่ทุกตัวตรวจว่าเป็น stable ล่าสุดและไม่มี known CVE ร้ายแรง (`npm audit` ผ่านก่อน commit)

model User { id String @id @default(cuid()); googleId String @unique; email String @unique; name String?; image String?; createdAt DateTime @default(now()); accounts Account[]; sessions Session[]; shelfItems ShelfItem[]; createdBooks Book[] @relation("CreatedBy") }

model Session { ... standard ... }
model VerificationToken { ... standard ... }

model Book {
  id String @id @default(cuid())
  googleBooksId String? @unique
  title String
  subtitle String?
  authors String[]
  categories String[]
  isbn10 String?
  isbn13 String?
  coverUrl String?
  publisher String?
  publishedDate String?
  description String?
  pageCount Int?
  language String?
  createdByUserId String? // manual book เท่านั้น

enum BookStatus { WANT_TO_READ READING READ }
model ShelfItem {

  bookId String
  book Book @relation(fields: [bookId], references: [id], onDelete: Cascade)
  status BookStatus @default(WANT_TO_READ)
  tags String[]
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
